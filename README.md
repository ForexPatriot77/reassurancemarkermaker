# Reassurance Marker Maker

A small, browser-based tool for creating illustrative roadside route reassurance markers.

## Features
- Interstate, U.S. Highway, and generic State Highway shield styles
- Editable route number and cardinal direction
- Optional directional arrow and roadside post
- Live SVG preview
- Export as SVG or PNG
- Responsive layout; no build step or dependencies

## Run locally
Open `index.html` in a modern browser. The app is entirely client-side.

## Important note
The designs are inspired by common U.S. route-marker conventions for mockups and educational use. They are **not official MUTCD sign drawings**, and this tool does not certify compliance with federal, state, or local standards. Do not use its output to manufacture or install real roadway signs.
